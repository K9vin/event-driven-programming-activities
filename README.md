# Event-Driven Programming Activities in Java

Comprehensive practical lab implementations and projects for the **Event-Driven Programming (EDP)** curriculum in Java.

---

## Curriculum Structure & Modules

| Module | Topic | Directory | Status |
|---|---|---|---|
| **Week 1** | **Introduction to Event-Driven Programming** (Components, Event Loop, Procedural vs. EDP, EDT Debugging, System Design) | [`week01-intro-to-edp/`](week01-intro-to-edp/) | Completed |
| **Week 2** | **The Observer Pattern** (Custom Subject-Observer, Deprecated `java.util.Observer` Analysis, Loose Coupling Refactoring) | [`week02-observer-pattern/`](week02-observer-pattern/) | Completed |
| **Week 3** | **Building GUI Applications with Swing** (Layout Managers, Component Hierarchy, EDT Single-Thread Rule) | [`week03-swing-gui/`](week03-swing-gui/) | Completed |
| **Week 4** | **Event Handling in Swing** (ActionListeners, Mouse/Key Events, Anonymous Classes vs. Lambdas) | [`week04-event-handling/`](week04-event-handling/) | Completed |
| **Week 5** | **Advanced Swing Components** (JTable, JTree, Custom Models, MVC in Swing) | [`week05-advanced-swing/`](week05-advanced-swing/) | Completed |
| **Week 6** | **Introduction to JavaFX** (Scene Graph, Stage & Scene, FXML, Modern Java UI) | [`week06-javafx/`](week06-javafx/) | Completed |
| **Week 7** | **JavaFX Event Handling** (Event Filters & Handlers, Event Bubbling/Capturing, Properties & Bindings) | [`week07-javafx-events/`](week07-javafx-events/) | Completed |
| **Week 8** | **Properties and Bindings in JavaFX** (Observable Properties, Change & Invalidation Listeners, Unidirectional & Bidirectional Bindings, Reactive Forms) | [`week08-javafx-bindings/`](week08-javafx-bindings/) | Completed |
| **Week 9** | **Asynchronous Programming in JavaFX** (`Task`, `Service`, `Platform.runLater()`, Real-Time Progress Feedback, Keeping the UI Responsive) | [`week09-async-javafx/`](week09-async-javafx/) | Completed |
| **Week 10** | **Final Project: University Management System** (EDA End-to-End: MySQL Data Layer, `Task` Background Queries, `ScheduledExecutorService`, FXML Navigation, Bindings) | [`week10-final-project-university-system/`](week10-final-project-university-system/) | Completed (requires MySQL) |

## Getting Started

### Prerequisites
- **Java Development Kit (JDK):** Version 17+ or OpenJDK 25 LTS
- **Git:** Version 2.40+
- **IDE:** Visual Studio Code or IntelliJ IDEA

### Clone the Repository
```bash
git clone https://github.com/K9vin/event-driven-programming-activities.git
cd event-driven-programming-activities
```
